## 已知边界

- 登录限流保存在单进程内存；生产部署保持一个 Web 进程，或在扩展为多进程前接入共享限流存储。
- 公网部署必须位于可信 HTTPS 反向代理之后，并正确设置安全 Cookie、可信代理与允许主机；默认 Compose 仅绑定回环地址。
- 项目只用于用户拥有或明确获授权管理的账号和令牌，与 Microsoft 没有隶属或背书关系。
